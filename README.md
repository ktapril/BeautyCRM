# BeautyCRM

Веб-приложение для автоматизации работы косметологического центра «Ангельский лик».

Проект разрабатывается как CRM-система с разграничением доступа для владельца центра, администратора, мастеров и клиентов.

## Технологии

### Backend
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- MySQL 8
- Maven
- JWT
- BCrypt
- JavaMailSender

### Frontend
- React
- TypeScript
- Vite
- CSS
- Lucide React

## Реализованные функции

### Клиенты
- Добавление, просмотр, редактирование и удаление клиентов.
- Поиск по имени, телефону и электронной почте.
- Карточка клиента с контактными данными.
- Загрузка и кадрирование фотографии клиента.
- Проверка загружаемых изображений.
- Хранение фотографий на сервере.

### Мастера
- Создание, просмотр, редактирование и удаление карточек мастеров.
- Хранение ФИО, специализации, телефона и электронной почты.
- Единый формат российских номеров телефонов.
- Проверка контактных данных.
- Синхронизация данных карточки мастера со связанным аккаунтом сотрудника.
- Поддержка официальных фотографий сотрудников.
- Личный кабинет мастера с просмотром собственных записей.
- Отображение количества всех, предстоящих и завершённых записей.
- Просмотр информации о клиентах, услугах, времени приёма, статусах и комментариях.

### Сотрудники
- Создание и редактирование аккаунтов сотрудников.
- Управление доступом сотрудников.
- Назначение ролей ADMIN и MASTER.
- Привязка аккаунта мастера к существующей карточке мастера.
- Автоматическое получение ФИО, телефона и электронной почты из карточки мастера.
- Отдельная настройка пароля для аккаунта сотрудника.
- Изменение статуса доступа к аккаунту.

### Записи
- Создание и просмотр записей через Backend API.
- Отображение списка записей в интерфейсе владельца и администратора.
- Отображение клиентa, мастера, услуги, даты, времени, статуса и примечания.
- Просмотр мастером только записей, назначенных на его карточку.
- Связь записи с клиентом и мастером через JPA.
- Проверка существования и доступности клиента и мастера.
- Проверка корректности длительности процедуры.
- Проверка даты записи.
- Проверка пересечения записей одного мастера.
- Поддержка статусов SCHEDULED, COMPLETED и CANCELED.

### Авторизация и безопасность
- Регистрация клиентов.
- Вход по электронной почте и паролю.
- Хеширование паролей с помощью BCrypt.
- JWT-аутентификация.
- Проверка токена при обращении к защищённым API.
- Подтверждение электронной почты.
- Автоматическое создание первого аккаунта владельца.
- Разграничение доступа по ролям.
- Ограничение доступа к операциям с данными в зависимости от роли пользователя.

### Роли пользователей

| Роль | Назначение |
|---|---|
| OWNER | Владелец центра, управление системой и сотрудниками |
| ADMIN | Управление рабочими процессами центра |
| MASTER | Аккаунт мастера и просмотр собственного расписания |
| CLIENT | Аккаунт клиента |

Открытая регистрация доступна только клиентам. Создание аккаунта владельца выполняется при первоначальной настройке приложения.

### Интерфейс
- Навигация по разделам CRM.
- Светлая и тёмная темы.
- Страницы авторизации и регистрации.
- Отображение интерфейса в зависимости от роли пользователя.
- Формы добавления и редактирования данных.
- Раздел расписания с таблицей записей для OWNER и ADMIN.
- Отдельный интерфейс личного кабинета MASTER.
- Автоматическое обновление данных с сервера каждые 10 секунд.
- Обновление данных при возвращении пользователя на вкладку или в окно приложения.

Автоматическое обновление реализовано через периодические HTTP-запросы (polling).

## База данных

Для хранения данных используется MySQL 8.

- Название базы данных: `beauty_crm`.
- Работа с базой данных осуществляется через Spring Data JPA и Hibernate.
- Связи между сущностями описываются средствами JPA.
- Настройка подключения выполняется через переменные окружения.
- Hibernate автоматически обновляет структуру таблиц при запуске приложения (`ddl-auto=update`).

Автоматическое обновление структуры удобно на этапе разработки. Для промышленной эксплуатации рекомендуется использовать систему миграций базы данных.

## Запуск проекта

### Требования

- Java 21
- Node.js и npm
- MySQL 8
- Созданная база данных `beauty_crm`

### Настройка переменных окружения

В корневой папке проекта необходимо создать файл `.env`.

Основные переменные:

| Переменная | Назначение |
|---|---|
| `DB_URL` | URL подключения к MySQL |
| `DB_USERNAME` | Имя пользователя MySQL |
| `DB_PASSWORD` | Пароль пользователя MySQL |
| `JWT_SECRET` | Секретный ключ JWT |
| `OWNER_EMAIL` | Электронная почта первого владельца |
| `OWNER_PASSWORD` | Пароль первого владельца |
| `OWNER_NAME` | Имя владельца |
| `FRONTEND_URL` | Адрес frontend |

Для отправки электронной почты дополнительно настраиваются:

- `MAIL_HOST`
- `MAIL_PORT`
- `MAIL_USERNAME`
- `MAIL_PASSWORD`
- `MAIL_FROM`

Секретные значения нельзя хранить в GitHub или исходном коде. Файл `.env` исключён из Git.

### Установка зависимостей

В корневой папке проекта:

```powershell
npm install
```

В папке frontend:

```powershell
cd frontend
npm install
cd ..
```

### Запуск Backend и Frontend

Из корневой папки проекта выполнить:

```powershell
.\start.ps1
```

Скрипт запускает оба сервера одновременно:

- Backend: `http://localhost:8080`
- Frontend: `http://localhost:5173`

Для остановки обоих серверов достаточно нажать `Ctrl+C`.

### Отдельный запуск

Backend:

```powershell
.\mvnw.cmd spring-boot:run
```

Frontend:

```powershell
cd frontend
npm run dev
```
